📘 Correct Workflow

  1. Choose SOP or POS.
  2. Place required values and optional X.
  3. Make the largest possible valid group.
  4. Correct groups remain on the map in different transparent colours.
  5. Each group immediately gives its matching coloured term.
  6. Final answer is verified only after every required target is covered.

Rules

SOP → group 1 + useful X.

POS → group 0 + useful X.

Sizes: 1, 2, 4, 8, 16, 32.

5-variable K-Map uses two 4×4 layers (A=0 and A=1). Corresponding cells in both layers are adjacent.

Rectangles only. Wrapping is allowed. Diagonal grouping is not.

Groups may overlap.

↔ Left–Right Wrapping

The orange right edge folds toward and overlaps the green left edge. So m0 ↔ m2, m4 ↔ m6, m12 ↔ m14, and m8 ↔ m10 are adjacent pairs.

↕ Top–Bottom Wrapping

The blue bottom edge folds upward and overlaps the red top edge. Therefore row {0,1,3,2} touches row {8,9,11,10}.

◰ Four-Corner Wrapping

When both directions wrap, m0, m2, m8, m10 meet at the boundaries and can form a single quad when their values allow it.
